Admin - Reports

Reports

Revenue Report

Revenue over a date range: total/items/shipping revenue, average order value, breakdown by payment method and a daily, weekly or monthly series.

Product Performance Report

All-time product sales: top sellers (by units), top by revenue, bottom performers and a units-by-category chart, with an optional category filter.

Customer Insights Report

Customer base metrics: total/new customers, repeat customer rate, average lifetime value and churn rate, with a new-customers-by-date line chart and a date range filter.
