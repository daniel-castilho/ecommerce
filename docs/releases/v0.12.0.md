## Summary

Closes the admin-dashboard **reporting lane** with the last story: **CSV/PDF export of the three
admin reports**. Every report page (`revenue`, `products`, `customers`) now shows **Export CSV** and
**Export PDF** buttons once a report has been generated. Downloads stream straight to the servlet
response with `Content-Disposition: attachment` (filenames embed the date range, or the product
category slug for S21) and stay inside the `/admin-dashboard/*` RBAC constraint. Export is a clean
seam: pure-Java `domain` models (`CsvTable`, `PdfDocument`, `PdfKeyValue`, `PdfSection`,
`ReportExportPort`, `ReportGenerationException` — zero framework imports) implemented by a single
adapter, `ReportGeneratorAdapter`, using the two human-approved dependencies **Apache Commons CSV
1.11.0** and **OpenPDF 1.3.43**.

## In scope (delivered)

- admin-dashboard domain (pure Java, no framework imports): `CsvTable`, `PdfDocument`,
  `PdfKeyValue`, `PdfSection` records, `ReportExportPort` (outbound port) and
  `ReportGenerationException`.
- admin-dashboard adapter: `adapter/out/reporting/ReportGeneratorAdapter` (`@ApplicationScoped`) —
  CSV via Commons CSV with a UTF-8 **BOM** (Excel-friendly) and header row; PDF via OpenPDF with a
  title band, KPI key/value cells, and per-series data tables styled from the design tokens
  (`#2C3E50`, `#2980B9`, `#F9FAFB`, `#BDC3C7`). Charts are exported as data tables, not images
  (right-sizing — no JFreeChart dependency).
- Report beans: `exportCsv()` / `exportPdf()` on `RevenueReportBean`, `ProductPerformanceReportBean`
  and `CustomerInsightsReportBean`, guarded by `isGenerated()`, using
  `ExternalContext.getResponse()` → `HttpServletResponse` + `FacesContext.responseComplete()`
  (mirrors the `LoginBean` response pattern). Product filenames include the category slug when a
  category filter is active.
- web: `Export CSV` / `Export PDF` buttons (secondary style, existing tokens only) on
  `reports/revenue.xhtml`, `reports/products.xhtml`, `reports/customers.xhtml`, rendered only after
  Generate.
- Dependencies (human-approved per AGENTS.md rule 6): `org.apache.commons:commons-csv:1.11.0`,
  `com.github.librepdf:openpdf:1.3.43` in `admin-dashboard/pom.xml`.
- Quality: 7 adapter unit tests (BOM, header, quoting, empty rows, null table; PDF `%PDF-` header,
  empty sections, null document) + 10/12/12 bean export tests (delegation, content type,
  `Content-Disposition` + filename, not-generated guard, port-failure path). Full gate green
  (`mvn clean package -pl web -am`: 85 + 65 + 6 + IT suites).

## Out of scope / explicit debt

- Charts are **not embedded** in PDFs — series are exported as data tables (no JFreeChart/Java2D
  dependency).
- No "Export PDF or CSV" dialog with a format radio — two dedicated buttons instead (right-sized).
- No Freemarker/HTML→PDF templating — direct OpenPDF document model.
- S23 closes the reporting lane; the admin-dashboard backlog has no remaining story with unmet DoD.

## How to validate

```bash
# Fast unit/ArchUnit (no Testcontainers):
mvn -q -pl admin-dashboard -am test -Dtest='ReportGeneratorAdapterTest,RevenueReportBeanTest,ProductPerformanceReportBeanTest,CustomerInsightsReportBeanTest,AdminDashboardHexagonalArchitectureTest' -DfailIfNoTests=false -Dsurefire.failIfNoSpecifiedTests=false

# Full build (final WAR):
mvn clean package -pl web -am

# Run (Open Liberty): ./scripts/run-liberty.sh
```

Smoke path (Open Liberty + Postgres):

1. Login `qa.admin@loja.com` / `SmokeTest@123` (ADMIN).
2. `GET /web/admin-dashboard/reports/revenue.xhtml` → only the filter form (no export buttons).
3. Click **Generate** → **Export CSV** / **Export PDF** buttons appear.
4. Click **Export CSV** → `revenue-report-<from>-<to>.csv` downloads, opens in Excel with UTF-8
   accents and one `Date, Revenue` + `Payment Method, Revenue` block.
5. Click **Export PDF** → `revenue-report-<from>-<to>.pdf` downloads, opens with title, KPI cells and
   the series tables.
6. Repeat on `products.xhtml` (filename includes category slug when filtered) and `customers.xhtml`
   (KPI rows + new-customers series).
7. A non-admin session hitting any export URL is rejected by the `/admin-dashboard/*` constraint.

## Lessons promoted

- #21 — OpenPDF (the `com.github.librepdf` fork) uses `java.awt.Color` / AWT types, not
  `com.lowagie.text.Color`; port iText5 examples with a compile check, and keep the library behind a
  domain seam (`ReportExportPort`) so churn never leaks into `domain/`.
