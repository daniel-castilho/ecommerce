## Summary

First story of the **admin-dashboard reporting lane (S20–S23)**: a **revenue report** over a
date range with payment-method breakdown and a daily/weekly/monthly series. Admins reach it via
`/admin-dashboard/reports/index.xhtml` (report selection) → `revenue.xhtml` (filters: from/to
date + group-by, Generate). The report shows Total Revenue, Items Revenue, Shipping Revenue,
Total Orders and Average Order Value as KPI cards, a CSS bar chart of revenue over time and a
payment-method breakdown table. Backed by `OrderRepositoryPort.revenueReport(from, to)` (JPQL
aggregates over `[from, to)`, excluding CANCELLED/REFUNDED) and `RevenueReportUseCase`
(`RevenueReportService` rolls the repository's daily series up to weekly/monthly). S20 is
**right-sized** to the current domain — no new dependencies were added (see notes).

## Out of scope / explicit debt

- **Total Tax / Net Revenue, Revenue by Category** — the order model has no tax column and order
  lines carry no category, so the report is right-sized to what exists (Items Revenue / Shipping
  Revenue instead). Deferred until the domain grows those fields.
- **Report Export (PDF/CSV)** — S23, deliberately **not** included: requires new dependencies
  (Flying Saucer/iText, Commons CSV) which need human approval per `AGENTS.md`.
- **PrimeFaces `<p:chart>`** — the spec's line chart was replaced by a dependency-free CSS bar
  chart (single occurrence, existing semantic tokens only).
- **S21 (Product Performance) and S22 (Customer Insights)** — remain open; Product/Customer
  entries on the reports index are shown as Planned.
- **Manual smoke QA not yet run** — the owner deferred it; the smoke path below is ready to run.

## How to validate

```bash
# Fast checks (no Testcontainers):
mvn -q -pl order-checkout test -Dtest='RevenueReportServiceTest' -DfailIfNoTests=false
mvn -q -pl admin-dashboard -am test -Dtest='RevenueReportBeanTest' -Dsurefire.failIfNoSpecifiedTests=false -DfailIfNoTests=false
mvn -q -pl web -am test -Dtest='AdminAccessControlCoverageTest,StatusBadgeCssCoverageTest' -Dsurefire.failIfNoSpecifiedTests=false -DfailIfNoTests=false

# ITs (Testcontainers Postgres):
mvn -pl order-checkout -am test -Dtest='OrderRepositoryJpaAdapterIT' -Dsurefire.failIfNoSpecifiedTests=false

# Full build (final WAR):
mvn clean package -pl web -am
```

Smoke path (Open Liberty + Postgres):

1. Login `qa.admin@loja.com` / `SmokeTest@123` → `catalog.xhtml`.
2. `GET /web/admin-dashboard/dashboard.xhtml` → KPIs render; the "Reports" card links to
   `/web/admin-dashboard/reports/index.xhtml`.
3. Open the revenue report, pick a date range and a granularity, Generate → KPI cards, bar
   chart and payment-method table render.
4. As a CUSTOMER user → `GET /web/admin-dashboard/reports/index.xhtml` is rejected
   (403 / login redirect).
