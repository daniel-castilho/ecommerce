## Summary

Second story of the **admin-dashboard reporting lane (S20–S23)**: a **product performance
report** over all-time sales — top 10 sellers by units, top 10 by revenue, bottom 10 performers
(warning-highlighted) and a units-by-category bar chart, with an optional category filter. Admins
reach it via `/admin-dashboard/reports/index.xhtml` → `products.xhtml`. It reuses the S20 pattern:
`OrderRepositoryPort.productSales()` (single JPQL `SUM(quantity)` / `SUM(quantity * unitPrice)`
grouped by productId, excluding CANCELLED/REFUNDED) merged with the product-catalog by productId
in `ProductPerformanceReportService`. The units-by-category chart is the **second** bar-chart
series, so the revenue-only CSS layout was extracted into the shared `barChart` component
(`WEB-INF/tags/bar-chart.xhtml`) per the design-system rule of two.

The **release QA sweep** (first browser QA executed in this lane) surfaced and fixed four bug
classes that predated or were introduced by S20/S21: a MyFaces composite-in-`ui:fragment` NPE that
500'd both report pages, a JSF enum-converter 500 on every admin "All" filter dropdown, a broken
`design-tokens.css` `@import` that silently dropped all design tokens, and the "plain-HTML
`rendered=` is a no-op" trap that made every empty-state message and gated card render
unconditionally across ~20 pages.

      - `bar-chart.xhtml` converted from a JSF composite (`cc:interface`) to a Facelet tag file

## Lessons promoted

- #19 — plain-HTML `rendered=` (and `styleClass=`) are **no-ops** in Facelets: only JSF/`ui:`
  components evaluate `rendered`. Empty-state `<p>`s and gated cards must be wrapped in
  `<ui:fragment rendered="…">`.
- #20 — CSS `@import` from a JSF-served stylesheet must use the FacesServlet resource URL
  (`design-tokens.css.xhtml?ln=css`), not a bare relative path — otherwise tokens silently never
  load.
- #21 — MyFaces throws `CompositeComponentDefinitionTagHandler` NPE (`compositeBaseParent is null`)
  for a composite component used inside `<ui:fragment>`; this repo's `WEB-INF/tags/` components are
  Facelet tag files, not `cc:` composites.
