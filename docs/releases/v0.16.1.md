# Release v0.16.1 — Catalog-card "Add to cart" (S11)

**Date:** 2026-08-09
**Git tag:** `v0.16.1`
**Baseline commit:** `0135365` (v0.16.0 — persistent cart S1–S10)
**DoD met:** yes (cart epic S11 complete; full unit/ArchUnit suite green, WAR builds; catalog
Add-to-cart smoke-verified in the browser on Open Liberty + Postgres)

---

## Summary

Patch release closing the persistent-cart epic's last (optional) story: an **Add to cart** button
on every catalog card. Logged-in customers add a product straight from the grid; guests see a
**Log in to buy** link (product-detail pattern). Reuses `CartBean.addProduct` (quantity 1) and the
existing global "Product added to your cart." message on the catalog page — no domain or
application changes.

## In scope (delivered)

- web: `product-catalog/catalog.xhtml` gains a per-card `h:form` with an **Add to cart** command
  button, rendered only for logged-in users when the product is `ACTIVE` and in stock (`product
 .status eq 'ACTIVE' and product.stock gt 0`); guests get a **Log in to buy** link to
  `/user-account/login.xhtml` under the same conditions. Styling reuses `.button
  button-secondary` and the existing `.product-card .button` rules — no new CSS.
- docs: `tasks/persistent-cart-backlog.md` marks S11 shipped (S12 guest cart remains explicit
  debt).

## Out of scope / explicit debt

- S12 guest cart + merge on login remains explicit debt (Won't for MVP).
- No AJAX/optimistic update — a full form post re-renders the card, consistent with the rest of
  the JSF storefront.

## How to validate

```bash
# Fast unit/ArchUnit (no Testcontainers):
mvn test -Dtest='*Test' -DfailIfNoTests=false

# Full build (final WAR):
mvn clean package -pl web -am

# Run (Open Liberty, https://localhost:9443/web/):
./scripts/run-liberty.sh
```

Smoke path (Open Liberty + Postgres, login `qa.admin@loja.com` / `SmokeTest@123`):

1. As a guest, open the catalog → each card shows **Log in to buy** (links to login), no Add to
   cart.
2. Log in, open the catalog → each card shows **Add to cart**.
3. Click it → the page shows "Product added to your cart."; the cart page lists the product.
